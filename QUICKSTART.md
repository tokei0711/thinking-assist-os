QUICKSTART

Thinking Assist OS Public

30 Second Quick Start

Thinking Assist OS helps humans continue.

You only need five commands.

---

Command 1

OS起動

Purpose:

Show:

- Current State
- Active Projects
- Recommended Next Actions

---

Command 2

選択肢

Purpose:

Generate possible next actions.

Use when you are unsure what to do next.

---

Command 3

SAVE

Purpose:

Convert experience into reusable knowledge.

Stored as:

- Lesson
- Success
- Failure
- Decision

---

Command 4

再開

Purpose:

Resume from where you stopped.

Restore:

- Goal
- Current State
- Previous Progress
- Next Action

---

Command 5

レビュー

Purpose:

Review progress.

Identify lessons.

Plan next actions.

---

Basic Workflow

OS起動

↓

Work

↓

SAVE

↓

レビュー

↓

再開

↓

Work

---

First Use

Type:

OS起動

and begin.
